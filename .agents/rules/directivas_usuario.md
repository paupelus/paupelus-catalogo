# DIRECTIVAS DE OPERACIÓN DEL USUARIO (MANDATORIAS)

1. **Ahorro de créditos y tokens estricto**:
   - Zero-fluff: Respuestas directas, hiper-concretas y sin rodeos ni introducciones innecesarias.
   - No gastar tokens repitiendo código o contexto no solicitado.

2. **Pruebas y validaciones**:
   - EL USUARIO HACE LAS PRUEBAS DE NAVEGACIÓN Y SQL.
   - NUNCA abrir navegadores automáticos, ni ejecutar subagentes de navegación o pruebas visuales por cuenta propia a menos que se solicite expresamente.
   - Solo generar o editar código, validar sintaxis rápida y entregar los archivos listos.
